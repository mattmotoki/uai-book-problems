Problem 3.3 (Comparing two mixtures, €50): answer "no"

Lean-checkedreview: faithful with caveats

Hutter asks: for two mixtures ξ, ξ′ over a class M, is Lξ − Lξ′ < ∞? Both totals are infinite, so the question is about the difference at time n. It grows without bound.

Let ν₀, ν₁, … enumerate (with repetitions) all lower semicomputable semimeasures with ν(ε) = 1. There are weights w⁻, w⁺, all positive, each summing to 1, with w⁻ᵢ/w⁺ᵢ ∈ [1/3, 3], such that ξ± = Σ w±ᵢ νᵢ are lower semicomputable, and an index j with νj = μ a computable probability measure. For binary 0-1 loss (ties toward 1): Lnξ⁻ − Lnξ⁺ ≥ n1/4/256 for all n ≥ 2, so the difference tends to +∞.
  • Lean: P33Mixture.mixture_counterexample. Also a simpler version with two computable measures (gap ≥ (1/32)·Hn, ties toward 0): MixtureCounterexample.counterexample.
  • Idea: the source picks one finite experiment j with probability 2−j−1 and biases 16j bits by 1/(32·4j). The two mixtures put weights ¼/¾ vs ¾/¼ on the two hypotheses, so they decide differently on a large part of each experiment.
  • Caveats: ties broken toward 1 only; on paper (not Lean) the class extends to the book's MU with ν(ε) ≤ 1; weights are not the 2−K(ν) prior; n1/4 agrees with the book's O(√L) upper bound.
  • Antecedent: Hutter, JMLR 2003, p. 988 shows one mixture's regret against μ can diverge (same mechanism, not two mixtures).

Problem 6.3 (Posterization, €100): last question answered "no"

Lean-checkedreview: faithful with caveats

Hutter asks whether the errors in cycles k..n can be bounded by ≈ 2K(zk:n | z<k).

With ordinary conditional prefix complexity, no constant C gives Ek:n ≤ C·2K(zk:n|z<k). This holds for AIξ and for every other deterministic predictor.
  • Lean: HutterPrizes.no_errorcount_complexity_bound. Witness: x = 0m, where m is the binary number of the adversarial bits, so K(y|x) = O(1) while errors grow like log m.
  • Caveats: it refutes the end of Hutter's chain, not the middle step (6.3N stays open); Chernov–Hutter's monotone K* version stays open.
  • Antecedent: Chernov–Hutter, ALT 2005, Lemma 5 (same length trick, for one-step deviation of M).
