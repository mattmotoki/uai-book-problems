## 3.3 `MixtureCounterexample.counterexample` — faithful, with stated caveats
- Problem 3.3 is on book p. 120 (not 119).
- Finite two-element class is allowed: eq. (3.5) p. 70 takes any countable M, finite explicitly; the book uses
  two-element classes itself (pp. 75, 77, Problem 3.6). No restriction to universal mixtures found.
- 0-1 binary loss is a special case of Theorem 3.48 (p. 87) and used by the book on p. 88.
- L^μ_n ≈ n/2, so the question is non-trivial (Cor. 3.49(i), p. 88). Result refutes sup-bounded, limit-exists,
  and abs-bounded readings. Growth (1/32) ln n is consistent with the proved O(√L) bound.
- Ties: the gap is ≥ 0 for every tie rule (reviewer's hand check); Lean proves one rule.
- Part 1 definitions: no bugs (mixCond = ξ(x1)/ξ(x); loss under μ = book's L^Λ (3.46); δ_t indexing correct).
- Not covered: two universal weightings over M_U (a stronger result).

## 2.7F `HutterPrizes.normalized_lower_bound` — faithful for the deterministic reading only
- Library M: root mass 1, lower semicomputable, maximal; mutually dominant with the book's M (2.21), so the
  bound transfers to every universal U up to a constant (two-line argument, not in Lean).
- Gives the analog of |1 − M(x_t|x_<t)| ≳ 2^-K(t) for M_norm, and of Σ|M − μ| only where μ is deterministic.
  The stochastic-μ analog (and (3.14)-(3.17)) is not established.
- Novelty risk: Leike-Hutter 2015 (arXiv 1507.04121) may already give the deterministic Θ(2^-K(t)) rate;
  Hutter has a TeXed "2.7u" solution. Check before any claim.
